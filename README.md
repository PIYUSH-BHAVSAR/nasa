

# SDGs in the Classroom

**Project Name**: SDGs in the Classroom  
**Event**: NASA Space Apps Challenge 2024  
**Date**: October 5-6, 2024  
**Team Role**: Web Design and JavaScript Functionality

## Project Overview
"SDGs in the Classroom" is a website developed during the NASA Space Apps 2024 Hackathon to raise awareness about the United Nations Sustainable Development Goals (SDGs). This platform serves as an educational tool to promote understanding and action towards achieving the 17 SDGs, making the goals accessible for students and educators alike.

### Goals and Features
- **Educational Awareness**: Introduces users to each of the 17 SDGs with engaging visual elements.
- **Data-Driven Insights**: Uses real data from NASA Earth Science datasets to showcase statistics and progress on global sustainability.
- **Interactive Visuals**: Includes charts and infographics generated using JavaScript to make complex data easy to understand.
- **AI-Generated Media**: Features images and visuals created with ChatGPT and AI tools to illustrate various SDGs.
- **Actionable Solutions**: Provides users with practical steps and suggestions for contributing to each SDG, helping individuals and communities take meaningful action.

## Key Contributions
- **Web Design**: Developed the frontend interface using HTML and CSS, ensuring a user-friendly and visually appealing layout.
- **JavaScript Functionality**: Implemented interactive charts to display data effectively, enhancing engagement with SDG statistics.
